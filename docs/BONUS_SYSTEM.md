# Система бонусов и штрафов для владельцев районов

## Обзор

Система бонусов и штрафов автоматически применяет дополнительные эффекты к владельцам районов на основе политиков, находящихся в этих районах. Система парсит текстовые описания бонусов из поля `bonuses_penalties` политиков и применяет их в различных игровых ситуациях.

## Компоненты системы

### 1. Парсер бонусов (`BonusParser`)

Парсит текстовые описания бонусов и создает структурированные правила.

**Поддерживаемые типы бонусов:**

- `CONTROL_POINTS` - Очки контроля (ОК)
- `FORCE` - Сила
- `MONEY` - Деньги
- `INFLUENCE` - Влияние
- `INFORMATION` - Информация

**Поддерживаемые условия:**

- `DEFENSE_DISTRICT` - При защите конкретного района
- `ATTACK_DISTRICT` - При атаке на конкретный район
- `DEFENSE_ANY` - При защите любого района
- `ATTACK_ANY` - При атаке на любой район
- `COOPERATIVE_ACTION` - При кооперативных действиях
- `MASS_ACTION` - При массовых акциях
- `IDEOLOGY_THRESHOLD` - При определенной идеологии района

### 2. Калькулятор бонусов (`BonusCalculator`)

Вычисляет и применяет бонусы в различных игровых ситуациях.

## Примеры использования

### Фиксированные бонусы за защиту района в цикл

```python
# Политик: Слободан Милошевич
# Бонусы: "+5 ОК за каждую заявку Атака/Защита"
# Результат: +5 ОК к control_points района каждый цикл

# Политик: Зоран Джинджич
# Бонусы: "+5 ОК в районах с +3 и больше"
# Результат: +5 ОК к control_points района, если идеология >= +3
```

### Специфические бонусы при создании действий

```python
# Политик: Желько «Аркан» Ражнатович
# Бонусы: "+3 Силы при Защите Подбары, -3 Силы при атаке на Подбару"
# Результат:
#   - При защите Подбары: +3 к силе действия
#   - При атаке на Подбару: -3 к силе действия

# Политик: Миролюб Лабус
# Бонусы: "+3 Денег при Кооперативных заявках, -3 Денег при любых Атаках"
# Результат:
#   - При кооперативных действиях: +3 к деньгам действия
#   - При атаках: -3 к деньгам действия
```

## Интеграция с игровым циклом

### 1. Бонусы за защиту района

Функция `grant_district_defense_bonuses()` вызывается в игровом цикле и:

- Анализирует всех политиков в районах
- Вычисляет фиксированные бонусы за защиту
- Начисляет бонусы к `control_points` районов
- Отправляет уведомления игрокам

### 2. Бонусы при создании действий

Функции `_apply_politician_bonuses()` и `_apply_politician_bonuses_on_create()`:

- Вызываются при создании и изменении действий
- Анализируют политика района действия
- Применяют специфические бонусы к ресурсам действия

### 3. Бонусы в боевых расчетах

Функция `resources_to_points_with_bonuses()`:

- Заменяет стандартную `resources_to_points()`
- Учитывает бонусы от политиков при конвертации ресурсов в очки
- Применяется в функциях обороны и атак

## Синтаксис описания бонусов

### Основные паттерны

```
+<число> <тип_ресурса> <условие>
-<число> <тип_ресурса> <условие>
```

### Примеры

```
"+5 ОК за каждую заявку Атака/Защита"
"+5 ОК в районах с +3 и больше"
"+3 Силы при Защите Подбары"
"-3 Силы при атаке на Подбару"
"+5 ОК при заявках на Защиту в любых районах"
"+3 Денег при Кооперативных заявках"
"-3 Денег при любых Атаках"
"+5 ОК при массовых акциях"
```

### Поддерживаемые ключевые слова

**Типы ресурсов:**

- ОК, очки контроля
- Силы, силы
- Денег, денег
- Влияния, влияния
- Информации, информации

**Условия:**

- "при Защите <район>"
- "при атаке на <район>"
- "при заявках на Защиту"
- "при Кооперативных заявках"
- "при массовых акциях"
- "в районах с +<число> и больше"
- "за каждую заявку Атака/Защита"

## Расширение системы

Для добавления новых типов бонусов:

1. Добавьте новый тип в `BonusType` enum
2. Добавьте паттерн в `BonusParser.PATTERNS`
3. Обновите логику применения в `BonusCalculator`
4. Добавьте обработку в функции применения бонусов

Для добавления новых условий:

1. Добавьте новое условие в `BonusCondition` enum
2. Добавьте паттерн в `BonusParser.CONDITION_PATTERNS`
3. Обновите логику проверки условий в `BonusCalculator`
