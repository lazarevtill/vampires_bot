# Функционал влияния на идеологию политиков

## Описание
Реализован механизм влияния на идеологию политиков через атаки с использованием ресурса "влияние".

## Как работает

### 1. Создание атаки
- Игрок создает атаку на район
- Выбирает количество влияния для трат
- Выбирает направление изменения идеологии политика:
  - **←** (влево): сдвиг идеологии влево на 1 пункт
  - **○** (не изменять): идеология остается прежней
  - **→** (вправо): сдвиг идеологии вправо на 1 пункт

### 2. Обработка атаки
- При обработке атаки сначала применяется изменение идеологии политика
- Затем вычисляются боевые очки атаки
- Идеология политика изменяется на 1 пункт в выбранном направлении
- Идеология ограничена границами от -5 до +5

### 3. Уведомления
- В новостях указывается, что идеология политика была изменена
- Игроки получают уведомления об изменениях

## Технические детали

### Модель данных
- Добавлено поле `ideology_shift` в модель `Action`
- Значения: -1 (влево), 0 (не изменять), 1 (вправо)
- Ограничение: CheckConstraint на диапазон -1..1

### UI изменения
- Добавлены кнопки выбора направления идеологии в экран атаки
- Кнопки показываются только для атак с тратой влияния
- В шаблоне отображается выбранное направление

### Валидация
- Проверка наличия политика в районе
- Проверка границ идеологии (-5..+5)
- Проверка трат влияния

### Логика обработки
- Функция `apply_ideology_shift()` применяет изменения
- Интегрирована в `resolve_attacks()`
- Логирование всех изменений

## Пример использования

1. Игрок создает атаку на район "Центр"
2. Тратит 3 влияния
3. Выбирает направление "→" (вправо)
4. При обработке атаки:
   - Идеология политика района "Центр" увеличивается на 1
   - Если была -2, становится -1
   - Если была 5, остается 5 (граница)
5. В новостях появляется сообщение об изменении идеологии

## Миграция базы данных
Необходимо создать миграцию для добавления поля `ideology_shift` в таблицу `actions`:

```sql
ALTER TABLE actions ADD COLUMN ideology_shift INTEGER CHECK (ideology_shift >= -1 AND ideology_shift <= 1);
```
